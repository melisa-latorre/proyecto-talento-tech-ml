Pre-entrega del proyecto final para el curso "Frontend-js" de Talento Tech. Se trata de una sitio web e-commerce del piloto de fórmula 1 Franco Colapinto. 
La página se estructura en tres archivos html (inicio, tienda y contacto) en las cuales se utilizaron las distintas etiquetas de html: header, main, section, footer, etc. El diseño es en su totalidad CSS.
